This directory stores reusable audio assets and runtime-generated narration.

Tracked in git:
- `default/kokoro-default/`: preview clips for Kokoro voices
- `default/typecast-default/`: preview clips for Typecast voices
- `default/sfx/`: reusable sound effects

Not intended for git:
- rendered narration generated during app usage
- dated sample runs
- exported MP4 files

Generated outputs should be written here at runtime and remain uncommitted.
